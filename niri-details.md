 Architecture                                                                                                                                                                                                       
                                                                                                                                                                                                                    
 - Login: greetd + dms-greeter --command niri (DMS-styled login screen, replaces GDM; greeter user via sysusers)                                                                                                    
 - Session: niri.desktop → niri-session; DMS starts as the dms.service user unit via /usr/lib/systemd/user/niri.service.wants/dms.service — the image-wide equivalent of the documented systemctl --user add-wants  
   niri.service dms                                                                                                                                                                                                 
- Packages: Fedora-native niri xwayland-satellite matugen dgop cava qt6-qtmultimedia wl-clipboard cliphist i2c-tools + COPR avengemedia/danklinux → quickshell dms-greeter danksearch, then avengemedia/dms → dms (isolated per copr_install_isolated). Order is load-bearing: dms/dms-greeter only require `(quickshell or quickshell-git)`, so dms must NOT resolve while quickshell is uninstalled or dnf takes Fedora's 0.2.x — the greeter then dies at QML parse (`//@ pragma AppId` needs quickshell ≥ 0.3) and greetd restart-loops into a frozen spinner. The script gates on a `//@ pragma AppId` probe via `qs -p` so a bad resolution fails the build instead of the boot.
 - Removed: gnome-shell gnome-session gnome-session-wayland-session gdm — base apps (Ptyxis, Files, Software, Settings) have no dependency on those and keep working                                                
 - Keybinds: Super+Space launcher, Super+V clipboard, Super+M task manager, Super+Comma settings, Super+N notifications, Super+Alt+L lock, Super+T Ptyxis

They read as ENOENT (greeter falls back to defaults), but clean them so a greeter bug hunt doesn't chase ghost state: `find /var/cache/dms-greeter -maxdepth 1 -type l ! -exec test -e {} \; -delete`.
